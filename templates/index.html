    Standar Format Baku 2026

    Setiap dokumen .docx memenuhi ketentuan tata tulis LabTIF Universitas Ahmad Dahlan.

    Kertas & Margin

    A4 Portrait dengan margin 3 cm pada sisi atas, bawah, kiri, dan kanan.

    Tipografi & Spasi

    Font Calibri 11pt (spasi 1.5, justified), Courier New 10pt berframe untuk kode program (spasi 1.0), dan istilah asing otomatis miring.

    Struktur Baku & Rubrik

    Cover resmi UAD 2026, Pre Test, Hasil Praktikum, Ulasan/Refleksi, Post Test, serta caption Capital Each Words.

    Kompresi Gambar

    Gambar diberi nomor otomatis (Gambar 2.1, 3.1, ...) dan dikompresi agar ukuran file ringan.

    Riwayat Laporan Anda

    Laporan yang pernah Anda generate tersimpan dan dapat diunduh ulang kapan saja.

    Pertanyaan Umum (FAQ)

    Jawaban cepat seputar penggunaan Laprakin.

    Apakah file .docx bisa langsung dikumpulkan ke portal?

    Sebaiknya periksa terlebih dahulu hasil .docx di Word, lalu simpan sebagai PDF sesuai ketentuan portal praktikum asisten masing-masing.

    Bagaimana jika halaman tertutup sebelum selesai?

    Laprakin menyimpan draft secara otomatis di local storage perangkat Anda, sehingga isian Anda akan dipulihkan saat halaman dibuka kembali.

    Kenapa modul Struktur Data dan Statistika meminta Nama PJ Asisten?

    Sesuai aturan penamaan file kedua modul tersebut, nama PJ Asisten disematkan langsung di akhir nama file resmi.
