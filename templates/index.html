    Standar Format Baku 2026

    Setiap dokumen .docx memenuhi ketentuan tata tulis LabTIF Universitas Ahmad Dahlan.

    01

    Kertas & Margin

    A4 Portrait dengan margin 3 cm pada sisi atas, bawah, kiri, dan kanan secara presisi.

    02

    Tipografi & Spasi

    Calibri 11pt (spasi 1.5, justified), Courier New 10pt berframe untuk kode, dan istilah asing otomatis miring.

    03

    Struktur Baku & Rubrik

    Cover resmi UAD 2026, Pre Test, Hasil Praktikum, Ulasan/Refleksi, Post Test, serta caption Capital Each Words.

    04

    Kompresi & Penomoran Gambar

    Gambar diberi nomor otomatis (Gambar 2.1, 3.1, ...) dengan prefix Ket : dan dikompresi agar ukuran file ringan.

    Pertanyaan Umum (FAQ)

    Jawaban cepat seputar penggunaan LabCraft.

    Apakah file .docx bisa langsung dikumpulkan ke portal?

    Sebaiknya periksa terlebih dahulu hasil .docx di Word, lalu simpan sebagai PDF sesuai ketentuan portal praktikum asisten masing-masing.

    Bagaimana jika halaman tertutup sebelum selesai?

    LabCraft menyimpan draft secara otomatis di local storage perangkat Anda, sehingga isian Anda akan dipulihkan saat halaman dibuka kembali.

    Kenapa modul Struktur Data dan Statistika meminta Nama PJ Asisten?

    Sesuai aturan penamaan file kedua modul tersebut, nama PJ Asisten serta jadwal slot disematkan langsung ke dalam nama file resmi.

    Apakah saya harus mengisi Gemini API Key secara manual?

    Jika server sudah dikonfigurasi dengan GEMINI_API_KEY, kolom API Key boleh dikosongkan dan tombol Generate AI tetap bisa langsung digunakan.

    Apakah screenshot bisa langsung di-paste tanpa disimpan dulu?

    Bisa. Cukup ambil screenshot (PrintScreen/Snipping Tool), lalu tekan Ctrl+V di halaman Step 2, Step 3, atau Step 4 untuk langsung menempelkannya.

    Bagaimana cara mengganti username atau kata sandi akun?

    Klik tombol profil nama Anda di pojok kanan atas navbar (sebelah tombol Keluar) untuk membuka menu Pengaturan Profil.
